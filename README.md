# Excel-Xbox
# 🎮 Dashboard de Vendas do Xbox — Excel

## 📊 Sobre o Projeto

Este projeto consiste na criação de um **Dashboard de Vendas do Xbox utilizando o Microsoft Excel**, com o objetivo de transformar dados brutos em informações visuais claras e organizadas.

O dashboard permite visualizar e analisar os dados de vendas de forma mais prática, facilitando a interpretação das informações e a identificação de padrões e resultados.

---

## 🎯 Objetivo

O principal objetivo do projeto é desenvolver um dashboard capaz de:

- 📈 Organizar dados de vendas;
- 📊 Apresentar informações de forma visual;
- 🔎 Facilitar a análise dos dados;
- 📋 Transformar dados brutos em informações úteis;
- 💡 Auxiliar na interpretação do desempenho das vendas.

---

## 🛠️ Ferramenta Utilizada

- **Microsoft Excel**
  - Tabelas e organização de dados
  - Tabelas dinâmicas
  - Gráficos
  - Filtros
  - Dashboard visual
